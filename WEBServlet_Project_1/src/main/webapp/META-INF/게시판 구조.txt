게시판 구조 정리

1. Model1 방식 게시판 예제
- JSP가 클라이언트 요청을 받고 화면을 출력합니다.
- DTO, DAO, Service 계층을 사용합니다.
- Servlet 컨트롤러는 사용하지 않습니다.

2. Model2 MVC 방식
- Servlet이 요청을 받고 흐름을 제어합니다.
- JSP는 화면 출력 역할을 담당합니다.

3. 게시판 종류
- 일반 게시판
- 계층형 답글 게시판
- 댓글 게시판
- 회원 전용 게시판
- 비회원 게시판

4. 주요 테이블
- jspboard: 게시글 저장
- reply: 댓글 저장

5. 계층형 게시판 컬럼
- refer: 원본 글 또는 답글 그룹 번호
- depth: 답글 깊이
- step: 답글 정렬 순서

6. 정렬 예시
- 일반 게시판: SELECT * FROM jspboard ORDER BY idx DESC
- 계층형 게시판: SELECT * FROM jspboard ORDER BY refer DESC, step ASC
